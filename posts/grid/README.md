# プロフィールグリッド12マス（文字 × 写真の市松）

いただいた参考画像（health & wellness coach のグリッド）の構成を分解して、
RAS® の内容に置き換えたものです。配色は3案つくったので `compare.png` で見比べてください。

---

## 1. 参考画像から取り出した「型」

参考にしたグリッドは、凝ったことは何もしていません。効いているのは3点だけです。

1. **文字タイルと写真タイルを1マスおきに置く**（市松）
2. **文字タイルの背景色を3色でまわす**（薄グレー → セージ → ベージュ）
3. **写真の色調を全部そろえる**（どれも彩度低め・明るめ・同じ色かぶり）

3つめが地味ですが一番大事です。写真をそのまま並べると1枚ごとに色がばらついて、
どれだけ文字タイルを整えても「まとまった1画面」になりません。
`photo_tile.py` は、この色そろえを自動でやるためのものです。

---

## 2. 市松が崩れない理由（投稿運用のコツ）

新しい投稿が入るたび、グリッドは1マスずつ右下にずれていきます。
そのため普通は「せっかく組んだ配置が1投稿で崩れる」のですが、
**列が3つ（奇数）なので、文字→写真→文字→写真…と交互に投稿しつづける限り、市松は自動的に保たれます。**

```
投稿順:  文 写 文 写 文 写 文 写 …

グリッド    文 写 文        写 文 写
（3列）     写 文 写   →    文 写 文
            文 写 文        写 文 写
```

左右の隣は1つ違い、上下の隣は3つ違い。どちらも奇数なので、必ず種類が入れ替わります。

つまり守るルールはひとつだけです。

> **文字タイルと写真タイルを、交互に投稿する。**

配置を考える必要はありません。順番さえ守れば勝手に市松になります。

> ピン留め3枚を置いている場合は、その3枚が最上段を占め、
> 以降が1行ぶん（＝3マス）ずれます。3は奇数なので市松のままです（白黒が反転するだけ）。

## 4. 配色3案

`compare.png` に並べてあります。

| 案 | フォルダ | 背景色 | 文字色 |
| --- | --- | --- | --- |
| **A `sage`** | 参考画像の配色そのまま | `#ECEEEC` `#D3DDD7` `#E4DCC3` | 灰緑・オリーブ系 |
| **B `meishi`** | **名刺の実配色** | `#F3EAE6` `#EBDEDE` `#DAC4BC` | `#8B5031` `#444342` |
| **C `ras`** | RASロゴの臙脂・朱・橙に寄せた | `#F4EDEA` `#EBD9D3` `#F3E3CE` | 臙脂・朱・琥珀 |

**おすすめは B `meishi` です。** 名刺から実際の値を読み取って組んだので、
名刺・グリッド・今後の印刷物が同じ色で揃います。写真タイルにかける色も
名刺の背景グラデーションの中間色なので、写真まで名刺と同じ空気になります。

- **A** は静かで無難ですが、名刺ともロゴとも色が離れます。
- **C** はロゴの赤に寄せた案。名刺より彩度が高く、少し華やかです。

### 名刺から読み取ったブランドカラー

共有いただいた Canva の名刺（`Release & Awakening System`）から取り出した実際の値です。
今後どの制作物でもこの4色を使えば、色がばらつきません。

| 用途 | 色 | 使われている場所 |
| --- | --- | --- |
| 背景グラデ（淡） | `#EBDEDE` | 名刺裏面の背景・上端 |
| 背景グラデ（濃） | `#CAAA99` | 名刺裏面の背景・下端 |
| 見出し | `#8B5031` | 「RAS®×東北」 |
| 本文・氏名 | `#444342` | 「及川 明美」「宮城県黒川郡大郷町」など |

書体は、英文が細めのセリフ体、和文が細めのゴシック体という組み合わせでした
（Canva 内部のフォントIDしか取得できないため、書体名までは特定できていません）。
グリッドの文字タイルは明朝体で組んでいるので、名刺の英文セリフとは近い雰囲気ですが、
完全に同じ書体ではありません。名刺と厳密に揃えたい場合は、Canva 側で使用フォント名を
ご確認いただければ差し替えます。

## 5. 写真タイルのつくり方

**いまグリッドに入っている写真タイルは仮のプレースホルダです。**
共有いただいた Drive フォルダにはロゴ・セッション資料PDF・音声しか入っておらず、
グリッドに使える写真がありませんでした。写真は別途ご用意ください。

### 名刺に使われている2枚が、そのまま候補になります

- **名刺おもて面の手元の写真** → `02`「手のひら・指先」にぴったりです
- **名刺うら面のお写真（及川さん）** → `10`「後ろ姿／横顔」に使えます

ただし名刺に配置された状態から切り出すと、1080x1350 には解像度が足りません。
**この2枚の元データ（撮影したときの元ファイル）**をお送りいただければ、そのまま変換します。

写真が用意できたら、次のコマンドでパレットに合わせた1080x1350のタイルに変換できます。

```bash
python3 photo_tile.py 手元.jpg meishi 02 --preview
python3 photo_tile.py 窓辺.jpg meishi 04 --focus top
python3 photo_tile.py 風景.jpg meishi 06 --strength 0.22
```

| 引数 | 意味 |
| --- | --- |
| 第1 | 元の写真 |
| 第2 | パレット（`sage` / `meishi` / `ras`） |
| 第3 | 何マス目に置くか（偶数マス） |
| `--focus` | 縦に余ったときどこを残すか（`top` / `center` / `bottom`） |
| `--strength` | パレット色をかける強さ 0〜1。強いほど統一感が出て、写真の個性は消えます |
| `--preview` | 変換後に `grid_preview.png` を作り直す |

### 写真選びの目安

- **明るく、余白が多く、主役が小さい**もの。文字タイルと張り合わない写真が向きます。
- 全部を同じ場所・同じ時間帯で撮ると、色そろえがほとんど不要になります。
- 顔出しが不要なら、手元・後ろ姿・持ち物だけで12マス組めます。

## 6. 投稿の順番と注意

1. **12 → 11 → 10 → … → 01** の順に投稿します（新しい投稿が左上に来るため）。
2. アップロード時のトリミング画面で、必ず **「元のサイズ（4:5）」** を選んでください。
   ここで正方形に切ると設計が崩れます。
3. 一気に12枚投稿する必要はありません。**交互の順番さえ守れば**、
   1日1枚ずつでも市松は成立します。

### グリッドは 3:4 に切り抜かれる

投稿は 4:5（1080x1350）ですが、プロフィールのグリッドでは 3:4 に切られ、
**左右が各 33.75px 削られます**。文字はすべて中央に寄せてあるので影響はありませんが、
写真を選ぶときは「左右の端に主役を置かない」ことだけ気をつけてください。
（この計算の詳細は `posts/profile-pin/README.md` に書いてあります）

## 7. 作り直す

```bash
python3 make_grid.py            # 3案とも作り直す
python3 make_grid.py meishi     # 案を指定
```

出力されるもの:

| ファイル | 内容 |
| --- | --- |
| `<案>/tile_01.png` 〜 `tile_12.png` | 投稿用（1080x1350） |
| `<案>/grid_preview.png` | グリッド（3列×4行）での見え方 |
| `<案>/sheet.html` / `sheet.png` | 文字タイル6枚の元データ |
| `compare.png` | 3案の並べ比べ |

### フォントについて

文字タイルは明朝体（IPAP明朝）で組んでいます。入っていない環境ではゴシックにフォールバックし、
印象がかなり変わります。明朝で出したい場合は次を入れてください。

```bash
apt-get install -y fonts-ipafont-mincho
```
