# プロフィールのピン留め3枚

> 案は2系統あります。図柄でつなぐ A/B/C 案（本文）と、
> 参考画像に寄せた `natural/` 案（末尾の追記）です。

## 1. 結論：ピン留め画像の「差し替え」はできません

Instagramは、**投稿済みの画像を後から別の画像に置き換える機能を持っていません**。
編集できるのはキャプション、タグ、位置情報、代替テキストまでです。

つまり、いま固定している「Release & Awakening System」の画像を変えたい場合は、
**新しく投稿し直して、そちらをピン留めする**ことになります。

### おすすめは「消さずに、外すだけ」

古い投稿を削除すると、その投稿についた閲覧数・いいね・コメントが消えます。
現在のピン留め2枚は 545 と 640 の再生数がついています。消すと戻りません。

そこで次の順番をおすすめします。

1. 古い投稿は **削除せず、ピン留めだけ解除**（時系列の位置に戻るだけで、残ります）
2. 新しい3枚を投稿する
3. 新しい3枚をピン留めする

ピン留めできるのは **3件まで** です。投稿の右上「…」から「プロフィールに固定」で操作します。

> 参考：カルーセル（複数枚）投稿の場合、アプリのバージョンによっては
> 編集画面で写真の削除や並べ替えができることがあります。
> 単写真の差し替えはできないので、まず編集画面を開いて確認してみてください。

## 2. グリッドの寸法（いただいたスクショから実測しました）

スクリーンショット（1170 x 2532）を解析した結果です。

| 項目 | 実測値 |
| --- | --- |
| 1マスの幅 | 390 px |
| 1マスの高さ | 519 px |
| 比率 | 390 ÷ 519 = **0.7507 → ちょうど 3:4** |
| マス間の隙間 | 約 2 px |

**プロフィールのグリッドは正方形ではなく、縦長の 3:4 です。**
ここが今回の設計の要になります。

---

## 3. 単純に3等分すると、なぜズレるのか

投稿として安全に使えるサイズは **4:5（1080 x 1350）** です。
ところがグリッドは 3:4 で表示するため、**左右が削られます**。

```
投稿画像　　1080 x 1350（4:5）
グリッド表示 1012.5 x 1350（3:4）
　→ 左右それぞれ 33.75px が切り落とされる
```

横長の1枚絵をそのまま3等分して投稿すると、
**各マスの左右 33.75px ずつ、合計 202.5px が消えます**。
線や図形が継ぎ目でプツプツ途切れるのは、ほぼこれが原因です。

### 対策：塗り足し（ブリード）を持たせる

`slice_banner.py` は、**グリッドに映る 1012.5px を基準に**分割し、
削られる 33.75px 分を隣の絵から借りて塗り足しています。

- グリッドで見たとき → 3枚が寸分ズレずにつながる
- 1枚を開いたとき → 塗り足し部分に隣の絵の続きが見えて、自然

```
マスター画像　3106 x 1350
　├ 左の塗り足し 33.75
　├ 表示部 1012.5 × 3列 = 3037.5
　└ 右の塗り足し 33.75
```

## 5. きれいにつなげるための工夫（今回入れたもの）

1. **継ぎ目そのものを図柄にする**
   マスの境界の真上に、ぼかした ∞ のモチーフを置きました。
   境界をまたぐ図形があると、目が勝手に「1枚の絵」として読みます。

2. **3枚を貫く1本の線**
   下部の細い横線が3枚を通して同じ高さに入っています。
   マス間の隙間（2px）で途切れても、太さ4pxあれば1本に見えます。

3. **01 / 02 / 03 の番号**
   左から右へ読む順番を指定できます。バラバラの3枚ではなく「組」に見えます。

4. **1枚だけ開いても意味が通るようにする**
   タップすると4:5の全体が表示されます。断片だと意味不明になるので、
   各マスに完結した一文を入れてあります。

5. **背景を全体で1枚のグラデーションにする**
   3枚別々に作らず、横に長い1枚として作ってから切る。
   これだけで色の段差が消えます。

6. **アプリの表示物を避ける**
   ピン留めアイコンは各マスの**右上**、閲覧数は**左下**に重なります。
   その2箇所には文字を置いていません。

7. **中央に寄せる**
   左右 33.75px は削られる前提なので、大事な要素は中央に寄せています。

---

## 6. 投稿とピン留めの順番

1. **`pin_03.png` → `pin_02.png` → `pin_01.png`** の順に投稿する
   （新しい投稿が左上に来るので、この順なら固定しなくても左から 01→02→03 に並びます）
2. 3枚それぞれの「…」から「プロフィールに固定」
3. 並び順が意図と違ったら、**3枚とも固定を解除して、逆の順で付け直す**

ピン留めの並び順はアプリの挙動に左右されるので、
一度並べてみて、違ったら付け直すのが確実です。

### 投稿時の注意

- アップロード時に**トリミング画面で必ず「元のサイズ（4:5のまま）」を選ぶ**
  ここで正方形に切ると、せっかくの計算がすべて崩れます。
- 画質を保つため、送信前に画像を圧縮アプリなどに通さないでください。

---

## 7. 作り直したいとき

文言や色を変える場合は `make_banner.py` の `COPY`（文言）と `THEMES`（配色）を編集し、
次のコマンドで3案とも一気に作り直せます。

```bash
python3 make_banner.py            # 全テーマ
python3 make_banner.py indigo     # テーマを指定
```

お手持ちの横長画像を分割したい場合は、高さ1350・幅3106に整えて
`slice_banner.py` に渡してください。2枚組にしたいときは `--cols 2` です。

```bash
python3 slice_banner.py 手持ちの画像.png 出力先/ --cols 3
```

## 8. 別案がほしいとき

- 写真を入れたい（お顔やサロンの写真を3枚にまたがせる）
- 2枚組にしたい
- 文言を変えたい
- ロゴをそのまま使いたい

いずれも対応できます。写真を使う場合は、元画像をお送りください。

# 追記：参考画像（britylyn / hanburydesignco.com 風）に寄せた案

## これまでの案との違い

| | A/B/C案 | 参考画像に寄せた `natural/` 案 |
| --- | --- | --- |
| つなぎ方 | 3枚を1枚の絵として**図柄でつなぐ** | **配色とタイポの統一**でつなぐ |

参考画像の作りは、横断する図柄をいっさい使っていません。
**同じ色・同じ組み方をひたすら繰り返すこと**で全体を1つに見せています。
継続して投稿していく前提なら、こちらのほうが崩れにくいです。

## 参考画像から抽出した配色

実際に画像から色を吸い出しました。

| 色 | コード | 用途 |
| --- | --- | --- |
| 淡いグレー | `#F2F2F0` | 文字タイル |
| セージグリーン | `#D7DDD9` | 文字タイル |
| ベージュ | `#E2DABB` | 文字タイル |

文字は明朝体を **字間 0.30em** で組み、色を落として（`#6E736C` など）
背景とのコントラストを弱くしています。参考画像の静けさはここから出ています。

## この見た目にするために、いちばん効くこと

文字タイルより **写真の色を揃えること** です。
参考アカウントの写真は、どれも彩度が低く、暖色寄りで、白っぽく仕上げてあります。
撮ったままの写真を混ぜると、そこだけ浮いてグリッドが散らかります。

`tone_photo.py` はその色調補正を自動でかけるツールです。

```bash
python3 tone_photo.py 元の写真.jpg 出力.jpg --crop
python3 tone_photo.py 元の写真.jpg 出力.jpg --crop --strength 0.7   # 効きを弱める
```

やっていることは4つです。

1. 彩度を 42% 落とす
2. コントラストを 14% 弱めてマットにする
3. ベージュ `#E2DABB` を 13% 重ねて色味を寄せる
4. 黒を少し持ち上げる（締まりすぎない黒にする）

`natural/tone_before_after.png` で効果を確認できます。

## 並べ方のルール

参考画像は **文字と写真の市松（チェッカー）** になっています。

```
行1   文字　文字　文字     ← ピン留め3枚
行2   写真　文字　写真
行3   文字　写真　文字
行4   写真　文字　写真
　…以下くりかえし
```

投稿するたびに「前回が写真なら今回は文字」と交互にするだけで、この形が保てます。
`stock/` の文字タイルは、そのための在庫です。
