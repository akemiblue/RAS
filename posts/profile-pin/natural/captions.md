ピン留め3枚（01〜03）と、通常投稿6枚（04〜09）です。
画像は `natural/pin_0*.png` と `natural/stock/post_0*.png` に対応します。

---

## 投稿の順番（重要）

**新しい投稿ほど左上に来る**ので、番号どおりに投稿すると並びが逆になります。
次の順で操作してください。

1. **01 → 02 → 03** を投稿し、それぞれ「…」から **プロフィールに固定**
2. 続いて **09 → 08 → 07 → 06 → 05 → 04** の順（逆順）で投稿

これで、グリッドは次のように並びます。

```
1行目（ピン留め）   RAS®︎とは       こんな方へ        体験・無料相談
2行目               解放して…       我慢することに…   本当はどうしたい？
3行目               「眠るのが怖い」 がんばり方を変える 私について
```

色（ベージュ / グレー / セージ）が縦にも横にも隣り合わないよう配置してあります。

### 一気に投稿するときの注意

6枚を続けて投稿すると、2行ぶんが文字タイルで埋まります。
参考にされたアカウントのような **文字と写真の市松** にはなりません。

市松にしたい場合は、**04〜09のあいだに写真を3枚はさんで**投稿してください。
写真は `tone_photo.py` で色調を揃えてからお使いください。
はさむ場合の順番は次のとおりです（これも逆順です）。

```
09 → 写真 → 08 → 07 → 写真 → 06 → 05 → 写真 → 04
```

そして、がんばり方の「向き」を決めているのが、信じ込みです。

### 注意書きを入れてある理由

01・02・05・07には、医療ではない旨や受診をすすめる一文を入れてあります。
不調や不眠に触れる内容は、書き方によっては
「治る」と受け取られかねません。ご自身を守るための一文なので、
短くしても構いませんが、残しておくことをおすすめします。

とくに07は「眠るのが怖い」という強い状態に触れています。
本当に助けが必要な方に届く可能性がある投稿なので、
受診をすすめる案内は必ず残してください。
