# 10年後の私の家（アルバム）

「こんな暮らしがいいな」と思った写真を、見つけるたびに一枚ずつストックしていくための
私的なアルバムです。Artifact として公開して、ブラウザから写真を入れていきます。

- 公開先：https://claude.ai/code/artifact/ad1b1d81-8d5b-40dd-9aa5-e2b1d1ca8b7c
- ソース：`album.html`（Artifact の本体。`<title>` と `<style>` を含む本文のみで、
  `<!doctype>` などの外枠は公開時に付与されます）

## 中身

7つの章に分けて写真を置いていきます。章は「部屋の名前」ではなく
「一日のどの時間の、どの気持ちか」で切っています。

| 章 | 名前 | 問い |
| --- | --- | --- |
| 一 | 朝のはじまり | 目がさめて、いちばんに見える光はどこから入ってくる？ |
| 二 | いちばん長くいる場所 | 一日のうち何時間もそこにいたい、と思える一角。 |
| 三 | 外とのあいだ | 窓の外、庭、縁側。家の内と外が混ざるところ。 |
| 四 | 誰かが来る日 | 人を招くとしたら、どこに座ってもらう？ |
| 五 | ひとりの時間 | 誰にも気をつかわずにいられる場所。 |
| 六 | 十年後の手ざわり | その家で使っているもの、着ているもの、手に持つもの。 |
| 他 | まだ名前のない一枚 | どこに置くか決まらないけれど、好きだと思った写真。 |

## できること

- 写真を入れる（ドラッグ＆ドロップ、またはクリックして選ぶ）
- 「ここが好き」を一行そえる。あとから書きかえられる
- 写真がまだ無いときは「言葉だけ入れる」で言葉のカードを置く
- 章を移す／一枚を外す
- 入れた写真と言葉は保存され、次に開いたときもそのまま残る

## しくみ

- 写真は `assets`（アルバム専用のファイル保管）に入り、返ってきた ID を
  `db` の `photos` コレクションに `{assetId, note, chapter, createdAt}` として記録します。
- 表示するときは ID から `/_blob/<id>` を組み立てて `<img>` に渡します。
- 端末から入れた写真は、保存前に長辺 1800px の WebP に縮小しています（容量対策）。
- 保存先につながらないビューでは、読むだけの表示に切り替わります。
