# マハトマエネルギー ― 偉大な魂とつながる

まありん 8月配信ボイスの内容を、そのまま読める1枚のページにまとめたものです。
ファイルは `index.html` の1枚だけで、外部ファイルへの依存はありません
（Webフォントのみ Google Fonts から読み込みます）。

## 見かた

ブラウザで `index.html` を開くだけです。ビルドもサーバーも不要です。
スマホでも読めるように、カード部分と項目表は横幅640px以下で1列に折り返します。

## 構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | 「偉大な魂」という言葉の意味と、エネルギーの出どころ |
| このエネルギーの本質 | 色・起源・頻度（1日最大3回）・向けられる先の4枚のカード |
| エネルギーが流れる道すじ | クラウン→大地までの7つのセンターと、対応する内分泌腺 |
| なぜ下垂体が鍵なのか | 老化の信念と、若さのホルモンを頼むこと |
| 降臨祈願のエクササイズ | 実践の7ステップ |

背骨のように縦に光が流れる線（`.spine-line`）と、各センターの光の粒（`.node::before`）が
このページの中心的なモチーフです。最後のベースセンターだけは大地の色（緑）に変わります。

## 手を入れるときのメモ

- 色はすべて `:root` のCSS変数にまとめてあります。基調はゴールデンホワイト
  （`--gold-bright` / `--gold`）と、着地点の大地の色（`--earth`）です。
- ステップ番号は `counter(step, decimal-leading-zero)` による自動採番なので、
  `.step` を増減させれば番号は自動でつけ直されます。
- 光の脈動（`.ray`）は `prefers-reduced-motion` を尊重して停止します。
