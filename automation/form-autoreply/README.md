# セッション申込フォーム 自動化（自動返信＋カレンダー登録）

対象フォーム：
`https://docs.google.com/forms/d/e/1FAIpQLSfuW72GzqXX8sTEY9QAQcapWS8weUz5tg3-Mu4Q432gbt73wQ/viewform`

申込が入ると、次の3つが自動で走ります。

1. 申込者へ **自動返信メール**（受付内容つき）
2. 希望日時を読み取って **Googleカレンダーに予定を作成**
3. 主催者へ **通知メール**（日時が読めなかった場合は「要確認」と明記）

---

## 事前に確認すること

- **フォームで「メールアドレスを収集する」がONになっているか**
  OFFの場合は、フォームに「メールアドレス」という記述式の設問を追加してください。
  どちらも無いと、自動返信の宛先が取れません。
- **希望日時の設問があるか**
  「日付」「時刻」形式が最も確実です。記述式でも `9/10 14:00` `9月10日14時` 等は読み取れます。
- このフォームは **akemi.789xyz@gmail.com** の所有です。
  設置作業には、そのアカウント、または編集権限を持つアカウントでのログインが必要です。

## 設置手順（10分ほど）

### 1. スクリプトを貼り付ける

1. フォームの編集画面を開く
2. 右上の **⋮（その他）→ スクリプト エディタ**
3. 既存の `コード.gs` の中身をすべて削除し、この `Code.gs` の内容を丸ごと貼り付け
4. 保存（Ctrl+S / ⌘S）

### 2. 設定を自分用に直す

ファイル冒頭の `CONFIG` を確認します。既定値は以下です。

| 項目 | 既定値 | 意味 |
| --- | --- | --- |
| `CALENDAR_ID` | `xakemix789@gmail.com` | 予定を入れるカレンダー（「明美の予定」） |
| `OWNER_EMAIL` | `xakemix789@gmail.com` | 申込通知の宛先 |
| `SENDER_NAME` | `RAS® 及川明美` | 自動返信の差出人名 |
| `SESSION_MINUTES` | `60` | セッション所要時間 |
| `INVITE_APPLICANT` | `false` | `true` にすると申込者を予定のゲストに追加 |
| `REMINDER_MINUTES` | `[1440, 60]` | 前日と1時間前に通知 |

自動返信の文面は `sendAutoReply_` 関数の中にあります。自由に書き換えてください。

### 3. 設問の読み取りを確認する（推奨）

1. 関数の選択欄で **`debugFields`** を選び、実行
2. 「実行ログ」に、設問一覧と自動判別の結果が出ます
3. `date1`（希望日）や `email` が `(該当なし)` になっていたら、
   `FIELD_KEYWORDS` に実際の設問名のキーワードを1語追加してください

### 4. トリガーを作る（ここが最重要）

1. **必ず `xakemix789@gmail.com` でログインした状態にする**
2. 関数の選択欄で **`setup`** を選び、実行
3. 承認画面が出たら「詳細」→「（プロジェクト名）に移動」→「許可」

トリガーは **実行した人の権限で動きます**。
つまり `xakemix789@gmail.com` で `setup` を実行すれば、
そのアカウントのカレンダーに予定が入り、そのアカウントのGmailから自動返信が送られます。
別アカウントで実行すると、そのアカウント側にカレンダー権限が必要になります。

### 5. テスト送信

自分でフォームに1件申し込んで、次の3点を確認してください。

- [ ] 自動返信メールが届く
- [ ] カレンダーに `【RAS体験】〇〇 様` の予定が入る
- [ ] 通知メールの1行目が `○ カレンダー登録済み` になっている

テストで作られた予定は手で削除してください。

## 動きの仕様

### 希望日時の読み取り

対応する書き方（全角も可）：

```
2026-09-10          → 9月10日 10:00（時刻未定として登録）
2026/09/10 14:00    → 9月10日 14:00
9月10日 14時30分     → 9月10日 14:30
9/10 ＋ 時刻欄10:30  → 9月10日 10:30
```

- 年の記載がない場合は今年。すでに過ぎた月日なら翌年とみなします。
- **時刻が読み取れなかった場合**は終日予定として登録し、タイトルに `【時刻要確認】` が付きます。
- **日付そのものが読み取れなかった場合**はカレンダー登録をせず、
  通知メールに `× 希望日時を読み取れませんでした` と出ます。手で登録してください。
- 電話番号を日付と誤認しないよう、電話系の設問は読み取り対象から除外しています。

### 失敗したとき

処理中にエラーが起きても申込データ自体は残ります。
その場合は `【要対応】申込フォームの自動処理でエラー` という件名のメールが届きます。

## 制限事項

- **Gmailの1日あたり送信上限は無料アカウントで100通**です。
  自動返信と通知で1申込あたり2通使います。
- 自動返信は「受付しました」の連絡です。**日程の確定連絡ではありません**。
  文面にもその旨を明記してあります。
- 申込者を予定のゲストに追加する（`INVITE_APPLICANT: true`）と、
  Googleから招待メールが別途届きます。二重に案内したくない場合は `false` のままに。
- ダブルブッキングの判定はしていません。必要であれば追加できます。

## よくある変更

**返信文を変えたい** → `sendAutoReply_` 内の `body` を編集

**所要時間を90分にしたい** → `CONFIG.SESSION_MINUTES` を `90` に

**別のカレンダーに入れたい** → Googleカレンダーの「設定と共有」でカレンダーIDをコピーし、
`CONFIG.CALENDAR_ID` に貼り付け

**自動化を止めたい** → スクリプトエディタ左の「トリガー」（時計アイコン）から
`onFormSubmit` のトリガーを削除
