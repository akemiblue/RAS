# RAS®︎ 体験・無料相談 申込フォーム 自動化

対象フォーム：**RAS®︎ 体験・無料相談 お申し込みフォーム**
`https://docs.google.com/forms/d/e/1FAIpQLSfuW72GzqXX8sTEY9QAQcapWS8weUz5tg3-Mu4Q432gbt73wQ/viewform`

申込が入ると、次の3つが自動で走ります。

1. 申込者へ **自動返信メール**（受付内容つき）
2. 希望日時を読み取り、カレンダー「明美の予定」に **仮の予定を作成**
3. AKEMI さんへ **通知メール**

## 確認済みのフォーム構成

実際の設問は以下でした。スクリプトはこの構成に合わせてあります。

| 設問 | 形式 | 必須 | 用途 |
| --- | --- | --- | --- |
| お名前 | 記述式 | ● | 予定タイトル・メール宛名 |
| なまえ(ふりがな) | 記述式 | ● | 予定の詳細欄 |
| メールアドレス | 記述式 | ● | **自動返信の宛先** |
| どちらかお選びください | 選択式 | ● | 予定タイトルに付記 |
| 注意事項やキャンセルポリシーの同意 | チェック | ● | 予定の詳細欄 |
| 実施方法のご希望 | 選択式 | ● | 予定の「場所」欄 |
| 希望日時(曜日・時間)を第3希望まで記入してください。 | 記述式 | ● | **カレンダー登録の元データ** |
| その他 | 記述式 | | 予定の詳細欄 |

- 「どちらかお選びください」の選択肢：`RAS®︎体験セッション` / `無料相談(zoom)`
- 「実施方法のご希望」の選択肢：`オンライン` / `自宅へ来てほしい` / `サロンへ行きます` / その他
- **メールアドレスの設問があるため、自動返信は問題なく動きます。**

## 希望日時の扱い（ここが肝心です）

このフォームの希望日時は **自由記述** で、記入例も `〇月〇日 午後、平日午前中。など` です。
つまり **確定した日時が入ってくる前提が置けません**。
勝手に予定を確定させると危険なので、読み取れた確度に応じて3通りに分けています。

| 回答の例 | 予定タイトル | 登録先 |
| --- | --- | --- |
| `9月10日 14:00` | `【仮】〇〇 様（RAS®︎体験セッション）` | 9/10 14:00〜 |
| `9月10日 午後` | `【仮・時間帯のみ】〇〇 様` | 9/10 14:00〜 |
| `9月10日` | `【仮・時刻未定】〇〇 様` | 9/10 終日 |
| `平日午前中` | `【要日程調整】〇〇 様` | **申込日**に終日 |

- どれも **仮予定** です。日程を確定させたら、ご自身で予定を直してください。
- 読み取れなかった場合も、申込日に `【要日程調整】` を置くので取りこぼしません。
- 第3希望まで書かれた場合、**最も確度の高い1件**を予定にし、
  **全候補を予定の詳細欄と通知メールに残します**。

読み取りの実績（テスト済み）：

```
9月10日 午後、9月12日 午前中、平日午前中
  → 9/10 14:00頃（時間帯のみ） / 9/12 10:00頃（時間帯のみ） / 読み取り不可

第1希望 2026/09/10 14:00 / 第2希望 9/12 10:30 / 第3希望 いつでも
  → 9/10 14:00 / 9/12 10:30 / 読み取り不可

１０月５日　夕方、10/6 午前     → 10/5 17:00頃 / 10/6 10:00頃
９月１５日（火）10:00〜         → 9/15 10:00
```

時間帯の言葉は次の時刻に割り当てています。変更は `CONFIG.SLOT_HOURS` で。

```
午前・朝 → 10:00 ／ 昼 → 12:00 ／ 午後 → 14:00 ／ 夕方 → 17:00 ／ 夜 → 19:00
```

## 設置手順（10分ほど）

### 1. スクリプトを貼り付ける

1. フォームの編集画面を開く
2. 右上の **⋮（その他）→ スクリプト エディタ**
3. 既存の `コード.gs` の中身をすべて削除し、`Code.gs` の内容を丸ごと貼り付け
4. 保存（Ctrl+S / ⌘S）

このフォームは **akemi.789xyz@gmail.com** の所有で、xakemix789 は編集者として招待されています。
編集者権限があればスクリプトエディタを開けます。

### 2. トリガーを作る（最重要）

1. **必ず `xakemix789@gmail.com` でログインした状態にする**
2. 関数の選択欄で **`setup`** を選び、実行
3. 承認画面が出たら「詳細」→「（プロジェクト名）に移動」→「許可」

トリガーは **実行した人の権限で動きます**。
`xakemix789@gmail.com` で実行すれば、そのアカウントのカレンダーに予定が入り、
そのアカウントのGmailから自動返信が送られます。
別アカウントで実行すると、カレンダーの共有権限が別途必要になります。

### 3. テスト送信

自分でフォームに1件申し込み、次を確認してください。

- [ ] 自動返信メールが届く
- [ ] カレンダーに `【仮】〇〇 様` の予定が入る
- [ ] 通知メールの1行目が `○ 仮予定を登録` になっている

テストで作られた予定は手で削除してください。

### 補助：確認用の関数

| 関数 | 用途 |
| --- | --- |
| `debugFields` | 設問名と自動判別の対応をログ出力。設問を変えた後の確認に |
| `debugParse` | 日時の読み取りだけを試す。実際の回答文を貼って確認できる |

## 制限事項

- **Gmailの1日あたり送信上限は無料アカウントで100通**です。
  1申込あたり自動返信と通知で2通使います。
- 自動返信は「受付しました」の連絡です。**日程の確定連絡ではありません**。
- ダブルブッキングの判定はしていません。仮予定が重なることはあり得ます。
- 処理中にエラーが起きても申込データは残ります。
  その場合 `【要対応】申込フォームの自動処理でエラー` という件名のメールが届きます。

## 自動化を止めたい場合

スクリプトエディタ左の「トリガー」（時計アイコン）から `onFormSubmit` を削除してください。
