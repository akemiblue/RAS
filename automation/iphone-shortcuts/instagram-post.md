# ショートカット①：投稿の下ごしらえ

**やること**：投稿を選ぶ → キャプションをクリップボードにコピー → Instagram が開く。ここまで1タップ。
あとは Instagram で写真を選んで、キャプション欄を**長押し → ペースト**するだけです。

**所要時間**：最初の組み立て15分（原稿の貼り付けを含む）／2回目以降は3秒

---

## はじめに：できること・できないこと

Instagram は外部からの自動投稿を許していません。**投稿ボタンを押すのは必ず手作業**です。
このショートカットが消すのは、その手前にある地味な手間のほうです。

| | 今まで | このショートカット |
| --- | --- | --- |
| 原稿を探す | メモAppを開いて、下にスクロールして…… | 投稿名を選ぶだけ |
| キャプションを選択 | 長押し → 範囲を指でドラッグ（毎回ずれる） | 自動でコピー済み |
| ハッシュタグ | 別の場所からもう一度コピー | メニューで選ぶだけ |
| Instagram を開く | ホーム画面に戻って探す | 自動で開く |

---

## 完成形

```
1  メニューから選択  「どの投稿ですか？」
     ├ 東北#01 我慢（本命）      → テキスト：本命キャプション
     ├ 東北#01 短縮（リール用）  → テキスト：短縮キャプション
     └ ストーリーズ告知          → テキスト：ストーリーズ用の文言
2  変数を設定  「キャプション」 ← メニューから選択の結果
3  テキスト   ハッシュタグ一式
4  変数を設定  「タグ」 ← テキスト
5  メニューから選択  「何をコピーしますか？」
     ├ 本文だけ            → クリップボードにコピー：キャプション
     ├ 本文＋ハッシュタグ  → テキスト（キャプション＋タグ）→ クリップボードにコピー
     └ ハッシュタグだけ    → クリップボードにコピー：タグ
6  通知を表示  「コピーしました。Instagram で長押し → ペースト」
7  Appを開く   Instagram
```

---

## 手順

### 0. 原稿を手元に用意する

このリポジトリの `posts/tohoku/01_oikawa-akemi_gaman.md` を開いて、次の3つをメモAppなどに写しておいてください。手順3・4・5で貼り付けます。

| 使う場所 | 原稿の場所 |
| --- | --- |
| 本命キャプション | 「## 1. キャプション（本命案）」の本文 |
| 短縮キャプション | 「## 2. キャプション（短縮案・リール／サブ投稿用）」の本文 |
| ハッシュタグ | 「## 5. ハッシュタグ」の25個 |

> iPhone だけで完結させたい場合は、GitHub の該当ファイルを Safari で開いてコピーしてもかまいません。

---

### 1. ショートカットを新規作成する

1. ショートカットApp → 「ショートカット」タブ → 右上の **「＋」**
2. 上部の名前部分をタップ → **`RAS 投稿下ごしらえ`** と入力

---

### 2. 投稿を選ぶメニューを作る

1. **アクション**：`メニューから選択` を追加
2. **「プロンプト」**の欄に **`どの投稿ですか？`** と入力
3. 最初は選択肢が2つあります。ここを次の3つにします
   - 1つ目をタップして **`東北#01 我慢（本命）`**
   - 2つ目をタップして **`東北#01 短縮（リール用）`**
   - **「新規項目を追加」** をタップして **`ストーリーズ告知`**

これで下に3つの分岐の帯ができます。

---

### 3. 各分岐にキャプションを入れる

**ここが一番間違えやすいところです。** アクションは必ず分岐の帯の**内側**に入れてください。
帯の下にある空白部分をタップしてから追加すると、そこに入ります。

1. 「東北#01 我慢（本命）」の下に **アクション**：`テキスト` を追加
2. そのテキスト欄に、手順0で用意した**本命キャプション**をペースト
3. 同じように「東北#01 短縮（リール用）」の下にも `テキスト` を追加し、**短縮キャプション**をペースト
4. 「ストーリーズ告知」の下にも `テキスト` を追加し、次のような文言を入れる

```
この言葉、心当たりありませんか？

▷ 新しい投稿を上げました
▷ アンケートスタンプ＋リンクステッカーを忘れずに
```

> 追加したアクションが分岐の外に出てしまったら、長押ししてドラッグで帯の中へ移動できます。

---

### 4. キャプションを変数にしまう

メニューの下（**すべての分岐が終わったあと**）に置きます。

1. **アクション**：`変数を設定` を追加
2. 「変数」欄に **`キャプション`** と入力
3. 「入力」欄をタップ → 変数バーから **`メニューから選択の結果`** を選ぶ

「メニューから選択」は、**選ばれた分岐の最後の結果**をそのまま返します。だから分岐ごとにコピー処理を書く必要がありません。

---

### 5. ハッシュタグを用意する

1. **アクション**：`テキスト` を追加
2. 手順0のハッシュタグをペースト（改行はそのままで大丈夫です）

```
#RAS #自分を大切にする #我慢しない生き方 #生きづらさ #自己肯定感
#本音で生きる #自分軸 #心の声 #セッション #カウンセリング
#コーチング #女性の生き方 #人生の後半戦 #家族関係 #嫁姑
#東北 #宮城県 #大郷町 #黒川郡 #仙台 #東北の女性
#50代女性 #60代女性 #言葉の力 #生き方を変える
```

3. **アクション**：`変数を設定` を追加
4. 「変数」欄に **`タグ`**、「入力」欄に変数バーから **`テキスト`** を選ぶ

---

### 6. コピーの仕方を選ぶメニューを作る

1. **アクション**：`メニューから選択` を追加
2. 「プロンプト」に **`何をコピーしますか？`**
3. 選択肢を3つにする
   - **`本文だけ`**
   - **`本文＋ハッシュタグ`**
   - **`ハッシュタグだけ`**

そして各分岐の中に入れていきます。

**「本文だけ」の中**

- **アクション**：`クリップボードにコピー` → 入力欄に変数 **`キャプション`**

**「本文＋ハッシュタグ」の中**

- **アクション**：`テキスト` → 欄の中で、変数 **`キャプション`** を入れる → **Enter を2回**押して空行を作る → 変数 **`タグ`** を入れる
- **アクション**：`クリップボードにコピー` → 入力欄に、直前の **`テキスト`**

**「ハッシュタグだけ」の中**

- **アクション**：`クリップボードにコピー` → 入力欄に変数 **`タグ`**

> ハッシュタグをファーストコメントに入れる運用のときは、投稿後にもう一度ショートカットを開いて「ハッシュタグだけ」を選べば、そのままコメント欄にペーストできます。

---

### 7. 仕上げ

メニューの下（すべての分岐のあと）に2つ足します。

1. **アクション**：`通知を表示`
   - 「タイトル」に **`コピーしました`**
   - 「本文」に **`Instagram のキャプション欄を長押し → ペースト`**
2. **アクション**：`Appを開く`
   - 「App」をタップ → **Instagram** を選ぶ

右上の **「完了」** で保存します。

---

### 8. ホーム画面に置く

1. 「ショートカット」タブで `RAS 投稿下ごしらえ` を**長押し**
2. **「共有」** → **「ホーム画面に追加」**
3. 名前を短く（例：`投稿`）して **「追加」**

---

## テスト

作り終えたら、一度通しで実行してください。

- [ ] ショートカットをタップすると「どの投稿ですか？」が出る
- [ ] 「東北#01 我慢（本命）」を選ぶと、次に「何をコピーしますか？」が出る
- [ ] 「本文＋ハッシュタグ」を選ぶと通知が出て、Instagram が開く
- [ ] Instagram でキャプション欄を長押し → ペーストすると、本文とハッシュタグが両方入る
- [ ] 本文の改行（`━━━━━━━━━━` の区切りなど）が崩れていない

改行が詰まってしまう場合は、手順3のテキスト欄にペーストし直してください。Safari からのコピーだと改行が落ちることがあります。

---

## 投稿を増やすとき

`#02` 以降が出てきたら、次の2箇所だけ足します。

1. 手順2の「メニューから選択」に **「新規項目を追加」**で投稿名を追加
2. できた分岐の中に **`テキスト`** アクションを追加してキャプションをペースト

手順4以降はそのままで動きます。

> 投稿が10本を超えたら、テキストを分岐ごとに持つ方式は重くなります。そのときは `辞書` アクションに「投稿名：キャプション」をまとめ、`辞書の値を取得`（すべてのキー）→ `リストから選択` → `辞書の値を取得` の3アクションに置き換えると、1画面で管理できます。必要になったら手順書を足します。

---

## 応用：ストーリーズに画像を直接出す

別のショートカット（名前：`ストーリーズへ`）として作ると便利です。

```
1  写真を選択        （「複数を選択」をオン）
2  クリップボードにコピー  ← 変数：告知の文言を入れた テキスト アクション
3  共有              → 実行時に Instagram ストーリーズ を選ぶ
```

`posts/profile-pin/` や `posts/grid/` の書き出し済み画像を iPhone の写真Appに入れておき、専用アルバム（例：`RAS投稿用`）にまとめておくと、手順1で迷いません。

---

## 制限事項

- **自動投稿はできません。** Instagram の仕様です。写真の選択と投稿ボタンは手作業になります。
- **クリップボードは1つだけ**です。コピーした後に別のものをコピーすると上書きされます。「コピー → すぐペースト」の順で使ってください。
- 原稿をショートカットの中に直接持たせる方式です。`posts/` の原稿を直したら、**ショートカット側も直す必要があります**。両方を直す前提で運用してください。
- ハッシュタグは Instagram の仕様上 **1投稿30個まで**です。上記は25個なので、追加するときは残り5個までに収めてください。
