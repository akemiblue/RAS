# ショートカット②：今日の問い（ジャーナル）

**やること**：タップすると、その日の「問い」がひとつ出てくる。答えを打つと、日付つきでジャーナルAppに残る。

RAS® のセッションでお聞きしているのは「あなたは、本当はどうしたいですか」のひとつだけ、という考え方を、
そのままご自身の1日に向けた形です。白紙の日記帳は続きませんが、**問いがあれば手が動きます**。

**所要時間**：組み立て10分／毎日の記入は1〜3分

---

## 必要なもの

| | |
| --- | --- |
| iOS | **18.1 以上**（ジャーナルへの書き込みアクションが使えるバージョン） |
| App | ジャーナル（iPhone に標準搭載。消していたら App Store から無料で戻せます） |

iOS が 17.x の場合は、[iOS 17 の場合](#ios-17-の場合) の代替版を使ってください。

確認：**設定 › 一般 › 情報 › iOS バージョン**

---

## 完成形

```
1  リスト               問いを10個
2  リストから項目を取得   ランダム項目
3  変数を設定            「問い」
4  入力を要求            プロンプト＝問い
5  変数を設定            「答え」
6  現在の日付
7  日付をフォーマット     2026年9月15日(火)
8  テキスト              〔問い〕＋答え を組み立て
9  エントリーを作成       ジャーナルに保存
10 通知を表示            「書けました」
```

---

## 手順

### 1. ショートカットを新規作成する

1. ショートカットApp → 「ショートカット」タブ → 右上の **「＋」**
2. 上部の名前部分をタップ → **`今日の問い`** と入力

---

### 2. 問いのリストを作る

1. **アクション**：`リスト` を追加
2. 「新規項目を追加」を押しながら、1行ずつ入れていきます

そのまま使える10個を置いておきます。ご自身の言葉に差し替えてください。

```
あなたは、本当はどうしたいですか
今日、飲み込んだ言葉はありましたか
今日いちばん、ほっとしたのはどの瞬間でしたか
「私さえ我慢すれば」と思った場面はありましたか
今日、自分のためだけに使った時間はどのくらいですか
体はどこが疲れていますか。そこは何を頑張ったのでしょう
明日ひとつだけ手放せるとしたら、何を手放しますか
今日の自分に、点をつけずに一言かけるとしたら
誰かの言葉で、いま胸に残っているものはありますか
いま、いちばん会いたい人は誰ですか
```

> 10個もいらなければ3個からで大丈夫です。あとから足せます。

---

### 3. 問いをひとつ選ぶ

1. **アクション**：`リストから項目を取得` を追加
2. 「取得」の欄が **「最初の項目」** になっているので、タップして **「ランダム項目」** に変える
3. **アクション**：`変数を設定` を追加
   - 「変数」に **`問い`**
   - 「入力」に変数バーから **`リストから項目を取得`** を選ぶ

---

### 4. 答えを書く欄を出す

1. **アクション**：`入力を要求` を追加
2. 「入力タイプ」が **「テキスト」** になっていることを確認
3. **「プロンプト」**の欄をタップ → 変数バーから **`問い`** を選ぶ
   （ここに問いが表示されます。固定の文言は入れません）
4. 「複数行を許可」のスイッチがあれば **オン**にする（長く書けるようになります。見当たらないバージョンならそのままで大丈夫です）
5. **アクション**：`変数を設定` を追加
   - 「変数」に **`答え`**
   - 「入力」に変数バーから **`指定された入力`** を選ぶ

---

### 5. 日付を用意する

1. **アクション**：`現在の日付` を追加
2. **アクション**：`日付をフォーマット` を追加
3. 「日付フォーマット」をタップ → **「カスタム」** を選ぶ
4. 「フォーマット文字列」に次を入力

```
yyyy年M月d日(E)
```

`2026年9月15日(火)` のように表示されます。曜日がいらなければ `(E)` を消してください。

---

### 6. 本文を組み立てる

1. **アクション**：`テキスト` を追加
2. 欄の中を、次のように作ります（`〔 〕` の中は変数、それ以外は手入力）

```
〔問い〕

〔答え〕
```

- 1行目 … 変数バーから **`問い`**
- Enter を2回押して空行
- 3行目 … 変数バーから **`答え`**

---

### 7. ジャーナルに保存する

1. **アクション**：`エントリーを作成` を追加（検索窓に `エントリー` と入れると出ます）
2. 「タイトル」の欄に、変数バーから **`フォーマットされた日付`** を選ぶ
3. 「本文」の欄に、変数バーから直前の **`テキスト`** を選ぶ
4. **アクション**：`通知を表示` を追加
   - 「タイトル」に **`書けました`**
   - 「本文」に、変数バーから **`問い`**

右上の **「完了」** で保存。

---

### 8. 1タップで呼べる場所に置く

**毎日やることなので、ここは必ず設定してください。** ショートカットAppを開くところから始まると続きません。

おすすめは次の3つです。

| 置き場所 | やり方 |
| --- | --- |
| **ロック画面** | ロック画面を長押し → カスタマイズ → 「ロック中の画面」 → 時計の下の枠 → ショートカット → `今日の問い` |
| **アクションボタン**（iPhone 15 Pro 以降） | 設定 › アクションボタン → 横にスワイプして「ショートカット」 → `今日の問い` |
| **ホーム画面** | ショートカットを長押し → 共有 → ホーム画面に追加 |

---

### 9. 毎晩、声をかけてもらう（任意）

決まった時刻に通知を出して、そこから書けるようにします。

1. ショートカットApp の下の **「オートメーション」** タブ
2. 右上の **「＋」** → **「時刻」**
3. 時刻を決める（寝る前の **21:00** あたりが続きやすいです）／「毎日」を選ぶ
4. 「次へ」→ **`今日の問い`** を選ぶ
5. **「実行前に尋ねる」を オフ** にする

文字を入力するショートカットなので、**時刻になると通知が出て、それをタップすると入力欄が開く**動きになります。
勝手に書かれることはありません。書かない日は通知を消すだけです。

---

## テスト

- [ ] 実行すると、問いが表示された入力欄が出る
- [ ] 何か書いて「完了」すると、通知が出る
- [ ] ジャーナルApp を開くと、日付がタイトルのエントリーができている
- [ ] 本文に「問い」と「答え」が両方入っている
- [ ] もう一度実行すると、**別の問い**が出る（同じ問いが続くこともあります。ランダムなので正常です）

## iOS 17 の場合

iOS 17.x にはジャーナルへ書き込むアクションがありません。**メモApp に残す形**に置き換えます。

手順2〜6までは同じ。手順7だけ差し替えます。

1. **アクション**：`メモを検索` を追加
   - 「フィルタを追加」→ 「名前」→ 「が次と一致」→ **`今日の問い`**
2. **アクション**：`メモに追加` を追加
   - 「メモ」の欄に、変数バーから **`メモ`**（検索結果）
   - 追加するテキストに、手順6の **`テキスト`** を入れる

あらかじめメモApp に **`今日の問い`** という名前のメモを1つ作っておいてください。そこに下へ下へと積み重なっていきます。

iOS を 18.1 以上に上げたら、この2つを消して `エントリーを作成` に差し替えれば、それ以降がジャーナルに入ります。

## 応用：セッションのふり返りを分ける

自分用の日記と、仕事のふり返りを分けたいときは、**手順2の前**に `メニューから選択` を足します。

```
1  メニューから選択  「どちらを書きますか？」
     ├ 今日の問い        → リスト（上記10個）
     └ セッションのふり返り → リスト（下記）
2  リストから項目を取得  ランダム項目
（以降は同じ）
```

ふり返り用の問いの例：

```
今日のセッションで、いちばん長い沈黙はどこでしたか
こちらが話しすぎた場面はありましたか
その方が、自分の言葉で言い直した瞬間はどこでしたか
次回までに、こちらが手放しておくべき見立ては何ですか
終わったあと、自分の体はどうなっていますか
```

**ここで書くときは、お名前を書かないでください。** イニシャルか「Aさん」で十分です。
ジャーナルは iPhone の中（と iCloud）にありますが、記録を残す以上、個人が特定できない形にしておくのが安全です。

---

## 制限事項

- ジャーナルApp は **iPhone・iPad・Mac 向け**です。Android やブラウザからは読めません。
- 書き出し（エクスポート）の仕組みが弱いApp です。長く残したい記録や、仕事で使い回す記録は、メモApp や別の日記Appのほうが向いています。
- ランダムなので、**同じ問いが連日出ることがあります**。気になる場合は、問いの数を増やしてください。
- 音声で残したい場合は `オーディオエントリーを作成` というアクションもあります。運転中や家事の最中に向いています。
