# iPhone ショートカット

iPhone の「ショートカット」App で組む手順書をまとめています。
アプリを入れる必要はありません。**iPhone に最初から入っている「ショートカット」App だけ**で動きます。

| 手順書 | 何ができるか | 所要 |
| --- | --- | --- |
| [instagram-post.md](instagram-post.md) | 投稿を選ぶ → キャプションとハッシュタグをコピー → Instagram を開く、を1タップで | 15分 |
| [journal.md](journal.md) | 今日の「問い」がランダムに出て、答えるとジャーナルAppに日記が残る | 10分 |

---

## 先に確認すること

### 1. iOS のバージョン

**設定 › 一般 › 情報 › iOS バージョン**

- **18.1 以上** … 両方そのまま作れます
- **17.x 以下** … ジャーナルの手順書は代替版（[journal.md](journal.md) の「9. iOS 17 の場合」）を使ってください
  ジャーナルを直接書き込むアクションが 18.1 で追加されたためです

### 2. ショートカットAppの場所

ホーム画面になければ、画面を下にスワイプして検索窓に `ショートカット` と入れてください。
消したつもりでも、App Store から無料で戻せます。

## 共通の操作（ここだけ覚えれば大丈夫です）

手順書の中で何度も出てくる操作です。

### 新しいショートカットを作る

1. ショートカットApp を開く
2. 下の **「ショートカット」** タブ
3. 右上の **「＋」**
4. 上部の名前部分をタップして、ショートカットの名前を入れる

### アクションを追加する

1. **「アクションを追加」**（または下部の検索窓）をタップ
2. アクション名を入力して検索
3. 出てきたものをタップ → 一覧の末尾に足されます

> 手順書では「**アクション**：〇〇」と書いてあります。その〇〇をそのまま検索してください。

### 変数（前のアクションの結果）を入れる

「ここに前の結果を入れる」という指示が出てきます。

1. 文章を入れる欄をタップ
2. キーボードのすぐ上に出る **変数バー** から、入れたいもの（例：`メニューから選択の結果`）をタップ

前のアクションの結果は自動で候補に出ます。見つからないときは、変数バー右端の **「変数を選択」** から探してください。

### アクションの順番を入れ替える・消す

- 入れ替え … アクションを長押しして、そのままドラッグ
- 消す … 左にスワイプ → 削除（または長押し → 削除）

## 作ったショートカットの置き場所

1タップで呼べる場所に置かないと、結局使わなくなります。どれか1つは必ず設定してください。

| 置き場所 | やり方 | 向いているもの |
| --- | --- | --- |
| **ホーム画面** | ショートカットを長押し → 共有 → ホーム画面に追加 | 両方 |
| **ロック画面** | ロック画面を長押し → カスタマイズ → ロック中の画面 → ウィジェット枠 → ショートカット | ジャーナル |
| **アクションボタン** | 設定 › アクションボタン → ショートカット（iPhone 15 Pro 以降） | ジャーナル |
| **コントロールセンター** | 画面右上から下スワイプ → 長押し → コントロールを追加 → ショートカット | 投稿下ごしらえ |
| **ウィジェット** | ホーム画面長押し → 編集 → ウィジェットを追加 → ショートカット | 両方 |

## うまく動かないとき

| 症状 | 原因と対処 |
| --- | --- |
| アクションが検索しても出てこない | iOS のバージョンが古い可能性。設定 › 一般 › ソフトウェアアップデート を確認 |
| 実行するとすぐ終わってしまう | 「メニューから選択」の分岐の中にアクションを入れ忘れている。分岐の帯の**内側**にあるか確認 |
| 変数バーに前の結果が出ない | そのアクションより**下**に置いた入力欄でないと候補に出ません。順番を確認 |
| Instagram が開かない | 「Appを開く」で選んだAppが正しいか確認。App が未インストールだと失敗します |
| ジャーナルのアクションがない | iOS 18.1 未満。[journal.md](journal.md) の代替版へ |

## 注意

- ショートカットの中に書いた文章（キャプション、問いの文言）は **iPhone の中にだけ**あります。
  機種変更時は iCloud 同期がオンなら引き継がれますが、念のため元の原稿は `posts/` 配下に残しておいてください。
- クライアントの固有名詞をショートカットやジャーナルに書き込む場合は、イニシャルなど**個人が特定されない形**にしてください。
